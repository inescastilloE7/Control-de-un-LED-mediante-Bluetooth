# Control de un LED mediante Bluetooth

Proyecto desarrollado para controlar de forma inalámbrica el encendido y apagado de un LED mediante un Arduino Uno y un módulo Bluetooth. Para su implementación se utilizaron un Arduino Uno, un módulo Bluetooth HC-05, un LED, tres resistores, una protoboard y cables de conexión. El sistema funciona mediante la recepción de comandos enviados por Bluetooth, los cuales son interpretados por el Arduino para encender o apagar el LED. Este proyecto permitió adquirir conocimientos básicos sobre la comunicación Bluetooth en Arduino y sentó las bases para el desarrollo de aplicaciones más complejas, como el control remoto de un rover mediante Bluetooth.
